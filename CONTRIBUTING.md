# Feedback ist willkommen

Bitte nutze die Issue-Vorlage für Fehler, Verständlichkeit und Einsatzwünsche. Öffentliche Issues können von anderen gelesen und kopiert werden.

- Nutze erfundene Namen und Daten.
- Nenne den ausgewählten Modus und gegebenenfalls die Fallnummer.
- Beschreibe, was du erwartet hast und was tatsächlich passiert ist.
- Teile keine Schlüssel, vertraulichen Berichte oder personenbezogenen Daten.
- Teste ausschließlich die angebotenen Demofunktionen; kein Lasttest oder Angriff auf fremde Infrastruktur.

Der private Produktkern nimmt über dieses Repository derzeit keine Codebeiträge entgegen. Für allgemeines Feedback ist kein Vertrag über eine Rechteübertragung vorgesehen.
