# Rechte und Testzugang

Dieses öffentliche Repository dient der Projektinformation und dem Feedback zu AI Guard Dog. Es enthält keinen zur Selbstinstallation freigegebenen Produktkern.

Für das Produkt wird durch diese Veröffentlichung keine Open-Source-Lizenz eingeräumt. Rechte bleiben vorbehalten, soweit sie bestehen. Gesetzlich erlaubte Nutzungen, Rechte an Drittmaterial und die für öffentliche Repositories geltenden GitHub-Bedingungen bleiben unberührt.

Eine bereitgestellte Online-Demo darf während ihrer Verfügbarkeit über die angebotene Oberfläche mit den vorgesehenen synthetischen Testfällen ausprobiert werden. Daraus folgt kein Recht auf Herausgabe des serverseitigen Quellcodes oder auf dauerhaft verfügbaren Betrieb.

Die Testphase kann pausiert oder beendet werden. Ein abgeschalteter Server nimmt keine neuen Testaufträge an. Bereits geladene Seiten, Screenshots und heruntergeladene Ergebnisse können beim Empfänger verbleiben.

Die öffentliche Beschreibung ist kein exklusiver Schutz einer Idee und keine Zusage, dass unabhängige Nachbauten verhindert werden können.
